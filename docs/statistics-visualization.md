# 统计可视化

入口：管理员端 → 统计报表 → 统计可视化（`/workspace/admin/reports/visualization`）。

页面直接使用 [Anime.js easing-editor](https://animejs.com/easing-editor) 的三栏布局样式：`public/assets/statistics/easings.css` 为官方 `assets/css/easings.css?v=1787698626` 的原文件。指标卡片复用 `easing-curve-items`，中栏复用 `easing-pane`、点状绘图背景、参数控件布局及底部刻度区域，右栏复用 Preview 网格、Export 页签布局和母版刷新/播放图标。顶栏、页脚、LOGO、英文及中文字体沿用项目已有素材。没有加载母版的广告、分析脚本或缓动编辑逻辑。

`statistics.css` 仅增加统计图、筛选表单、数据明细及响应式适配；图表使用 SVG，不引入图表库。支持楼栋床位柱图、派工/完工双系列折线图、完成率及评分环图。所有图表都有数值明细，支持键盘选择、鼠标悬停数值、关闭入场动画、重播和系统减少动态效果偏好。

12 项指标均读取现有 `GET /api/v1/statistics`：楼栋入住率、总床位、入住床位、空闲床位、报修总量、完成率、每月派工、每月完工、平均评分、评价数量、账单数量和待缴金额。保留现有接口的权限和筛选范围；未修改数据库结构。楼栋选择清单来自全范围统计结果，不受当前楼栋筛选影响。

日期按报修提交时间和账单生成时间筛选；床位始终是当前状态。每月维修工作量按筛选到的报修所对应的派工月份归集。账单数量包含已缴清账单，待缴金额为当前余额；空闲床位不包括维修、停用床位。页面明确标注这些口径。

筛选条件及指标保存在地址栏，刷新和浏览器历史可恢复；默认显示全部范围。图表项目数可调整，明细保留全部数据。导出调用现有 `statistics/export`，与当前楼栋和日期条件保持一致，CSV 保留原有机器可读格式。界面日期及金额遵循项目公共格式化函数。

验证：`npm run test:integration -- --statistics-browser` 在独立测试库验证实际数值、图表切换、筛选、刷新、导出、失败重试、零数据、管理员权限和 1536/900/390 像素布局。`tests/statistics-visualization.ts` 另校验比率、月份数据及空数据不产生 NaN。
