# 学生工作台设计与共用约定

学生工作台地址为 `/workspace/student`，使用 Anime.js Docs 母版适配的三栏布局。学生、宿管、维修人员和管理员均使用独立 Docs 外壳；管理员统计可视化使用独立的 easing-editor 外壳。

## 外壳与页面清单

学生外壳位于 `public/assets/student/`。左侧是角色功能目录，中间是可滚动的动画预览，右侧是正文、业务组件及相邻页面导航。母版搜索、目录展开、选中颜色、预览重播、最小化和手机菜单由保留的运行时处理。

页眉提供项目 Logo、搜索、工作台、项目 GitHub 与账号按钮；中间栏不显示跳转 CodePen 的编辑图标。页脚提供 HOME、WORKSPACE、项目和开发者链接及 FLIGHT INC. 署名。母版原始样式和脚本保持受保护状态，中文字体通过公共字体样式适配。

页面清单由 `src/features/workspace/config/student-pages.ts` 汇总模块、功能、提交和记录页面。对外地址使用语义化路径，详情编号和分页等放在查询参数；内部页面文件名与动画标识可保留母版兼容名称。完整地址见 [WORKSPACE_ROUTES.md](WORKSPACE_ROUTES.md)。

六个模块分别为个人信息、住宿业务、缴费管理、报修服务、公告查看和个人消息，依次使用红色、珊瑚橙、橙色、黄色、柠黄色和青柠色。侧栏、搜索、预览与正文使用相同主题映射；父模块和子页的标识分别唯一。

## 正文与业务元素

| 业务 | 当前呈现方式 |
| --- | --- |
| 个人资料 | 使用 Installation 标题、代码框和复制按钮展示本人资料与住宿信息 |
| 修改资料与密码 | 使用可编辑代码块、确认／取消、字段校验及密码遮罩；改密后撤销会话 |
| 入住、调宿和退宿 | 功能主页提供提交与记录入口；提交页使用可编辑代码块，记录页使用摘要导航列表，详情展示真实审核与床位结果 |
| 账单与缴费 | 导航列表展示摘要，代码框展示明细，在线缴费承接测试支付与余额刷新 |
| 报修与评价 | 提交、当前进度、历史记录和评价分别使用独立子页；处理过程以母版表格显示 |
| 公寓通知、缴费提醒与消息 | 导航列表展示标题和状态，详情使用文档正文段落并确认本人阅读状态 |

字段编辑使用的铅笔、确认和取消控件属于业务表单。空数据使用母版 INFO，读取失败和校验错误使用 WARNING；不得在接口尚未返回时提前显示“暂无记录”。详情中的文本按普通文字呈现，保留换行，不执行用户输入的 HTML。

页面切换保留母版正文渐显、顶部定位、面包屑和底部相邻导航。三级目录和详情面包屑沿用原有空白节点及箭头结构。iframe 负责滚动，外层不产生重复滚动条。

## 真实数据与权限

`StudentDocsPage` 只接受同源、来自自身 iframe 的允许页面标识，并将业务组件挂载到母版正文。身份由主应用认证上下文与服务端确认；URL、动画标识及跨文档消息不能授予权限。

业务组件继续调用同源 `/api/v1` 接口。资料、申请、账单、报修、公告和通知均受本人或楼栋范围限制。列表和详情缓存按账号、会话隔离，保存成功后失效或重新验证。具体接口、事务和报修自动初审规则见 [BACKEND_API.md](BACKEND_API.md)。

日期、金额显示分别使用中文日期和人民币符号；API、CSV 与表单值保持机器可读格式。金额及未读数量预览读取真实汇总，不受当前列表分页影响，达到目标值后停止。动画配置和数字口径见 [STUDENT_PREVIEWS.md](STUDENT_PREVIEWS.md)。

## 导航提醒

四端共用 `NEW` 标记，规则位于 `src/features/workspace/config/navigation-signals.ts`。学生端可提示待缴账单、未读提醒、未读消息及业务进展，并聚合到父目录。待办在实际处理后消除；需要阅读确认的内容在详情呈现后确认相应版本，预加载不会标记已读，新版本再次提醒。

## 生成与资源保护

`scripts/sync/sync-student-navigation.ts` 同步学生导航和页面片段，并调用预览同步；`scripts/sync/sync-student-previews.ts` 根据专属映射更新预览。其他三端复用学生端的 CSS、Docs 运行时及原始演示，再由各自生成脚本与桥接层适配。

完整 `documentation-demos.html` 是生成预览的源素材，`documentation-archive-map.js` 是现用路径适配器；这些名称不表示文件可以删除。`tests/fixtures/student-template-source.json` 用于资源摘要校验。

运行工作台不需要本机母版目录。完整离线同步脚本及部分对照测试仍会读取原始母版目录，执行前需要按脚本中的来源路径准备只读素材。宿管业务适配见 [MANAGER_WORKSPACE_DESIGN.md](MANAGER_WORKSPACE_DESIGN.md)。

## 验证

`tests/checks/student-template.ts` 校验母版摘要和外壳结构，`tests/e2e/shared/workspace-paths.ts` 校验页面地址，`tests/e2e/student/navigation.ts`、`student-breadcrumbs.ts`、`student-themes.ts` 和 `student-transitions.ts` 验证目录、面包屑、主题及渐显。

学生各业务的浏览器回归覆盖真实提交、列表与详情、失败恢复、本人范围、直达刷新和手机布局。完整业务回归使用独立测试数据库，截图写入被忽略的 `test-results/screenshots/`，不修改本机课程业务数据。
